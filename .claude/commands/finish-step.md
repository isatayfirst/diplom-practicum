---
description: Закрыть текущий шаг: проверки, ROADMAP, SESSIONS
---
1. Проверь критерии приёмки шага из ROADMAP.md по пунктам; запусти `npm run lint` и `npm run build`.
2. Обнови статус шага в ROADMAP.md.
3. Добавь запись СВЕРХУ в SESSIONS.md (не длиннее ~15 строк): что сделано, что проверено, проблемы, следующий шаг. Если записей больше 4, старшие перенеси в docs/archive/.
4. Отчитайся автору: критерии (выполнено/нет), что проверено, что осталось. Коммить только после слова автора; после коммита сразу push.
